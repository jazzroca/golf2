GitHub Pages 웹사이트 무료 배포 가이드

누구나 3분 안에 인터넷에 우리 홈페이지를 올릴 수 있어요!

  1. HTML 파일 저장:
    현재 생성된 이 코드를 index.html 로 컴퓨터에 저장합니다.
  2. 사진 파일 준비:
    올려주신 사진 파일 이름을 1000013592.jpg 로 두고, index.html 과 같은 폴더에 위치시킵니다.
  3. GitHub 저장소(Repository) 생성:
    GitHub에 로그인 후 New Repository 클릭 (예: golf-diary). Public으로 설정합니다.
  4. 파일 업로드:
    생성된 저장소에 index.html 과 1000013592.jpg 를 드래그앤드롭하여 커밋(Commit)합니다.
  5. GitHub Pages 켜기:
    저장소 상단 Settings > 좌측 Pages 메뉴 이동 > Branch를 main (또는 master)으로 선택하고 Save 클릭!
    👉 약 1분 후 https://아이디.github.io/저장소이름/ 주소로 전 세계 어디서든 접속 가능합니다!
